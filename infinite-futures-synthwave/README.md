# Infinite Futures (synthwave)

The liquid-metal ocean as an 80s arcade racer. The camera drifts forward forever; move the cursor to look around (drag on touch screens).

- A neon dusk: hot pink horizon, violet sky, fine stars.
- A huge striped sun fixed ahead, half sunk into the sea, its stripes slowly scrolling.
- A cyan grid that rides the chrome swells and slides beneath you as you travel.
- A CRT finish: curved screen, slight colour fringing, scanlines, rounded edges.

Derived from [`../infinite-futures/`](../infinite-futures/). WebGL2, no dependencies, no build step.

Serve the repo root and open `/infinite-futures-synthwave/`:

```bash
python -m http.server 8000
```
